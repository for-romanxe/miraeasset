# 연금 개념 정리 (팀 공통 상식)

Agent 답변의 근거는 반드시 제공 문서(parser/out/docs/)에서 찾아야 한다.
이 문서는 팀원이 도메인을 이해하기 위한 요약이다.

## 큰 그림: 3층 구조

1층 국민연금(국가) / 2층 퇴직연금(회사) / 3층 개인연금(본인).
**이 과제의 범위는 2·3층 = 사적연금.**

## 계좌(제도) 층위

| 구분 | 누가 쌓나 | 누가 굴리나 | 특징 |
|---|---|---|---|
| DB 확정급여형 | 회사 | 회사 | 급여 확정: 평균임금 × 근속연수. 근로자는 신경 쓸 것 없음 |
| DC 확정기여형 | 회사(연봉 1/12↑) | **근로자** | 운용 결과에 따라 수령액 변동 → 상담 수요·디폴트옵션의 무대 |
| IRP 개인형 | 본인(+퇴직금 입금) | 본인 | 퇴직금 받는 그릇 + 자유 추가납입 |
| 연금저축 | 본인 | 본인 | 회사 무관, 누구나 가입. 세액공제의 중심 |

**계좌와 상품은 다른 층위다.** "IRP에서 솔로몬 펀드를 산다" — 계좌는 세제·규칙을
정하는 그릇, 상품은 내용물. 질의가 어느 층위인지 구분이 라우터의 첫 임무.

- 그릇(제도·세제) 데이터 = 안내문서 58건 (parser/out/docs/)
- 내용물(상품) 데이터 = 투자설명서 100건 (parser/out/funds.json)

## 상품 층위

- 원리금보장형: 예금·GIC. 원금 보장
- 실적배당형: 펀드·ETF. 운용 실적 따라 손익 — **투자설명서 100건이 여기**
- 상품 6축: 상품분류(자산유형) · 위험등급(1위험~6안전) · 판매클래스 · 총보수 · 수익률 · 시장잔고

## 세제: 돈의 일생 (수치는 docs 원문으로 재확인할 것)

1. **넣을 때 — 세액공제**: 연금저축 연 600만원, IRP 합산 연 900만원 한도.
   공제율 총급여 5,500만원 이하 16.5% / 초과 13.2% (900만원 → 최대 148.5만원 환급).
   납입 자체는 연 1,800만원까지. 공제 초과 납입도 이점 있음(doc44)
2. **굴리는 동안 — 과세이연**: 일반계좌는 이자·배당에 15.4%, 연금계좌는 0.
   세금 몫까지 재투자되는 복리 효과 (doc36·42·43)
3. **받을 때 — 저율 과세**: 55세 이후 + 가입 5년 + 연금 형태 수령 시
   연금소득세 5.5%(55~69) → 4.4%(70대) → 3.3%(80~).
   사적연금 연 1,500만원 초과 시 종합과세 이슈(doc38).
   연금수령한도(doc39)·수령연차(doc40) 규칙이 "연금으로 인정되는 금액"을 정함
4. **중간에 깨면 — 페널티**: 기타소득세 16.5%. 예외적 중도인출 사유
   (무주택 주택구입·요양·파산 등)는 doc46~50

## 퇴직금 별도 트랙

일시금 수령 시 퇴직소득세 전액 부과. **IRP로 받아 연금 수령하면 30% 감면
(11년차부터 40%)** (doc51). 참고 질의 "명퇴 교사 절세"가 이 트랙 + 세액공제 복합 문제.
임원은 퇴직소득 한도 초과분이 근로소득 과세(doc45).

## 자주 나오는 개념

- **디폴트옵션(사전지정운용)**: DC·IRP에서 만기 후 방치 시 사전 지정 상품으로
  자동 운용. 관련 문서 4건(doc29~32) — 질의 빈출 주제
- **실물이전**: 상품을 팔지 않고 금융사 이동 (doc34·35)
- **위험등급**: 1=가장 위험 ~ 6=가장 안전. "안정적인 걸 원해요" →
  funds.json `risk_grade >= 5` 필터로 번역
- **소규모 펀드**: 자본총계 50억 미만 → 임의해지 위험 고지 대상 (funds.json `is_small_fund`)

## 참고 질의 5개 ↔ 데이터 매핑

| 질의 | 루트 |
|---|---|
| DB/DC 차이 | docs 검색 (doc11·15) |
| 세액공제 한도 | docs(doc41) + 계산기 |
| 명퇴 교사 절세 | docs(doc26·51) + 계산기 |
| 솔로몬 국공채 비교 | funds.json 필터 + 투자설명서 |
| 좋은 상품 추천 | 역질문 분기 (조건 수집 후 조건부 결론) |
