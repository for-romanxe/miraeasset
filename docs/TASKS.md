## 공통 규칙

- main 직접 푸시 금지. 브랜치 → PR → `python eval/run_eval.py` 점수 확인 → 머지
- 새 기능을 만들면 평가셋에 검증 문항도 같이 추가
- 수치·규칙은 반드시 parser/out/docs/ 원문에서 확인 (기억으로 쓰지 않기)
