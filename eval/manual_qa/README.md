# 수동 점검용 시험 질문 세트

제출 전 최종 점검용 질문 모음. **평가셋(`eval/evalset.jsonl`)과 별개**로, 사람이 답변 품질을 눈으로 검수하기 위한 것이다. 담당자별로 검수 관점을 나눴다.

| 파일 | 담당 | 문항 | 검수 관점 |
|---|---|---|---|
| `시험질문-연성-세제계산-100.txt` | 연성 | 100 | 계산값이 계산기와 일치, 혼동쌍(1,500/1,800/900/600/700) 구분, 전제교정 |
| `시험질문-승빈-안전경계-100.txt` | 승빈 | 100 | 공격 거절, 정상질문 오탐 방지, 한계 고지, 슬롯별 역질문/가정 |
| `시험질문-승빈-안전경계-300.txt` | 승빈 | 300 | 위와 동일, 확장판 |
| `시험질문-석규-검색표현-100.txt` | 석규 | 100 | 구어체·오타 검색, 절차 문서, 비교표, 조건 분기, 복합 질문 |
| `시험질문-석규-검색표현-300.txt` | 석규 | 300 | 위와 동일, 확장판 |

총 900문. 각 파일 상단 주석에 세부 확인 포인트가 있다.

## 각자 자기 컴퓨터에서 실행하기 (승빈·석규)

**한 번만 하는 세팅:**

```bash
git clone <레포 주소> miraeasset && cd miraeasset
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
# 연성에게 받은 HCX 키를 .env 에 넣는다 (커밋 금지, .gitignore 등록돼 있음)
echo 'CLOVASTUDIO_API_KEY=<전달받은 키>' > .env
```

**실행 (레포 루트에서):**

```bash
set -a && . ./.env && set +a
.venv/bin/python eval/manual_qa/batch_check.py eval/manual_qa/시험질문-승빈-안전경계-300.txt
```

- 데모 서버 불필요 — 파이프라인을 직접 호출한다(기본값).
- 옵션: `-n 20`(앞 20문항), `--start 51`(51번부터 이어서), `--http`(데모 서버로 실행).
- 문항당 5초 페이싱. 300문항 ≈ 60~75분.
- **⚠️ HCX 키가 계정 공유라, 세 명이 동시에 돌리면 서로 429가 난다. 단톡방에서 시간을 나눠 각자 순서대로 돌릴 것.**

## 리포트 보는 법

- 실행하면 질문 파일 옆에 `<파일명>-리포트.md`가 생긴다(중간 저장 — 끊겨도 `--start`로 이어서).
- 문항마다 🟢/🔴. 🔴 = 재확인 문구(※)가 붙었거나 검증에서 미확인/미지지가 나온 문항.
- **검수**: 🔴를 열어 ①진짜 결함 ②판정 기준 문제(실은 정상) ③애매 로 분류. 진짜 결함만 이슈 #66에 취합. 🟢도 표본 10개는 정독해 품질 확인.
- 리포트 md는 커밋하지 않는다(`.gitignore` 등록됨).
