# 수동 점검용 시험 질문 세트

제출 전 최종 점검용 질문 모음. **평가셋(`eval/evalset.jsonl`)과 별개**로, 사람이 답변 품질을 눈으로 검수하기 위한 것이다. 담당자별로 검수 관점을 나눴다.

| 파일 | 담당 | 문항 | 검수 관점 |
|---|---|---|---|
| `시험질문-연성-세제계산-100.txt` | 연성 | 100 | 계산값이 계산기와 일치, 혼동쌍(1,500/1,800/900/600/700) 구분, 전제교정 |
| `시험질문-승빈-안전경계-100.txt` | 승빈 | 100 | 공격 거절, 정상질문 오탐 방지, 한계 고지, 슬롯별 역질문/가정 |
| `시험질문-승빈-안전경계-300.txt` | 승빈 | 300 | 위와 동일, 확장판 |
| `시험질문-석규-검색표현-100.txt` | 석규 | 100 | 구어체·오타 검색, 절차 문서, 비교표, 조건 분기, 복합 질문 |
| `시험질문-석규-검색표현-300.txt` | 석규 | 300 | 위와 동일, 확장판 |

총 900문. 각 파일 상단 주석에 세부 확인 포인트가 있다.

## 실행 (batch_check.py)

데모 서버(`scratchpad/demo/demo.py`, 실제 파이프라인 재사용)를 띄운 상태에서:

```bash
python eval/manual_qa/batch_check.py eval/manual_qa/시험질문-연성-세제계산-100.txt
python eval/manual_qa/batch_check.py <파일> -n 20        # 앞 20문항만
python eval/manual_qa/batch_check.py <파일> --start 51   # 51번부터 이어서
```

- HCX 실호출이라 문항당 5초 페이싱 (계정 한도 분당 60요청/6만 토큰 공유). **셋이 동시에 돌리지 말 것.**
- 문항마다 🟢/🔴 판정, `<파일명>-리포트.md`로 중간 저장 (끊겨도 이어서 가능).
- 🔴 = 재확인 문구(※)가 붙었거나 검증에서 미확인/미지지가 나온 문항. 사람은 🔴를 열어 ①진짜 결함 ②판정 기준 문제 ③애매 로 분류하고, 진짜 결함만 취합한다.
